# TALUS — Authorship and development provenance

## Project relationship

TALUS is a project associated with Tennessee Tech's Autonomous Robotics Club (ARC). The original electronics, firmware, software architecture, CV/IK integration, simulation tooling, and dashboard work published here as this repository's TALUS-specific contribution were independently developed by **Tyler Krumm** (**Me-Smrt** on GitHub), rather than jointly implemented by the club. The club's project affiliation should not be interpreted as a claim that the code and hardware designs here were authored collaboratively.

Third-party mechanical platforms, reference materials, code dependencies and pretrained models remain the intellectual contributions of their respective creators; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The original author statement covers only work actually created by the repository author, and is subject to applicable institutional/sponsored-project agreements.

## Why the earliest Git commit is not the project start

The TALUS design and implementation process began locally **before this Git repository was initialized**. The first commit imports an existing source snapshot. It does not reproduce all earlier local revisions, prototypes, or tests.

The repository intentionally excludes generated Blender projects, pretrained model weights, local runtime databases, vendor CAD assets, and private development archives. Their absence from Git does not imply that those activities were not part of development.
