DOCUMENTATION / SUPPORT

Help

The dashboard is a local presentation layer. Robot safety and actuator authority remain in the Pi hardware-control process, CCB Supervisor, and RCB firmware.

STATE

Robot state

System, safety, node, perception, camera, audio, motion, and auxiliary-link health are read from the Pi control-plane API.

VISION

Camera views

Raw and processed views are point-in-time JPEG snapshots. The dashboard does not open a continuous raw stream from the Pi.

STATUS

Node colors

Green means the Pi reports healthy. Red means an explicit fault/offline state. Amber/gray means unknown, unconfigured, or not yet verified.

AUTHORITY

Authenticated controls

Login protects operator pages, but authentication alone never grants a way around hardware safety. Safety-critical controls will require a separate deliberate command contract.
