# Parking and Transportation

Snapshot date: 2026-09-29. Category: campus.

The campus parking map that took effect August 14, 2026 identifies student, employee, reserved, visitor, accessible and other parking areas. Students parking on campus are expected to register for the appropriate parking permit. Because lot designations, shuttle routes and construction zones can change, use the current public parking map for precise directions rather than relying solely on this snapshot.
