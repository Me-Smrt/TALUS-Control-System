# Majors and Academic Catalogs

Snapshot date: 2026-09-29. Category: academics.

The undergraduate catalog provides the authoritative public list of majors, concentrations, requirements and pre-professional career tracks. Some career tracks are not themselves Tennessee Tech degrees; they guide students toward later professional programs. Because degree names, concentrations, prerequisites and requirements can change, answers about a specific program should be grounded in the current catalog snapshot or referred to the Registrar/academic department when the local archive is incomplete.
