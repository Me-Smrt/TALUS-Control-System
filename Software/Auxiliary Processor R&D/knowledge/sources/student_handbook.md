# Student Handbook

Snapshot date: 2026-09-29. Category: policies.

The public Student Handbook is a central index for student rights, responsibilities and many campus policies. Topics include academic policies, FERPA/confidentiality, conduct, complaints, Title IX, discrimination/harassment, housing policy, fee adjustments/refunds, financial aid, IT acceptable use, inclement weather and use of campus property. For legal or disciplinary questions, use the current handbook/policy text rather than a summary.
