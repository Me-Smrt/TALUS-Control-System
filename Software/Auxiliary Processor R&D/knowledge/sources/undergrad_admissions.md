# Undergraduate Admissions and Application

Snapshot date: 2026-09-29. Category: admissions.

The public application page supports undergraduate first-time and transfer applicants, international undergraduate applicants, and graduate applicants through separate pathways. As of this snapshot it lists Spring 2027, Summer 2027 and Fall 2027 undergraduate application options. It lists a $25 one-time application fee for domestic undergraduate applicants, $35 for graduate applicants, and $40 for international undergraduate applicants, with transcripts required and possible program-specific materials. Admissions contact: admissions@tntech.edu or 931-372-3888.
